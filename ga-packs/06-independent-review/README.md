# Pack 06 — Independent Security Review

## Objective

Obtain a genuinely independent review of architecture, authentication, authorization, sandboxing, supply chain, recovery, operations, privacy and release controls.

## Required proof

The reviewer must provide identity and organization, methodology, conflict-of-interest declaration, reviewed commit, source and release digests, finding counts and a report digest. The completed report must be signed with a reviewer-controlled key and verify as a release-bound DSSE proof.

## State

`READY_FOR_REVIEWER` — deterministic dossier, report contract and proof verification are implemented; an external reviewer has not yet completed or signed the review.
