# PSMatrix release assets

This directory stores public, non-secret release and GA-operation bundles.

## 2.0.0rc2

- Security hardening bundle
- GitHub vulnerability-pipeline bundle
- Independent security-review operation bundle
- Authoritative Windows operation bundle
- Release manifest, verification result, and public key

Every file is bound by `2.0.0rc2/SHA256SUMS.txt`.
